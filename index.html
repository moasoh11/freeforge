AI theme (free AI)
About the AI features: when you press an AI button, only the text you typed is sent to the free Pollinations text API (open GPT-OSS 20B model, run by a third party, anonymous, about one request per 30 seconds per connection). Nothing else is uploaded; do not type personal information. AI output is validated and clamped before use. Everything else runs in your browser.
Use it: .rbxmx: in Studio right-click StarterGui, Insert from File. Luau: paste into a LocalScript in StarterPlayerScripts. Every part is a real editable Frame, TextButton, UICorner, UIStroke. No flat images.
